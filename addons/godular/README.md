# Godular

Modular architecture for Godot. Godular lets you split a game into modules that declare what they provide and what they depend on, and it wires everything together for you.

- Documentation: <https://rafaelvidaurre.github.io/godular/>
- Source and issues: <https://github.com/RafaelVidaurre/godular>

Godular needs Godot 4.5 or later and the bundled `addons/gd_promise` addon. Enable "Godular" under Project Settings, then Plugins. The plugin adds the `GdlrModuleManager` autoload.

The Godular classes are documented in the editor help (F1).
